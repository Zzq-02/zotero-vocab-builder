# Zotero 生词笔记

Original project name: `Vocabulary Builder`

Collect unfamiliar English words while reading in Zotero, and store them in a dedicated vocabulary note with translation, context, and source links.

## What It Does

- Add a word while reading a PDF, EPUB, or note in Zotero — via a floating button that appears when you select text, or via a keyboard shortcut (default `Alt+A`, customizable in Settings).
- Store every collected word in one dedicated Zotero note instead of a separate database.
- Auto-extract the full sentence containing the selected word as context, and save the source link for each word.
- Jump back from the vocabulary note to the original selection position in the PDF.
- Fill in translation, definition, part of speech, and phonetic data automatically.
- Pronounce any word in the vocabulary note with one click (TTS).
- Cache translation results locally (offline dictionary): previously looked-up words show their meanings even when offline. The cache path is configurable in Settings.
- Keep pending words when offline and retry translation later.
- Add words in bulk (one per line) from the Settings pane.
- Export vocabulary as CSV, TSV, JSON, Anki, Quizlet, or Mochi.

## Where The Words Are Saved

The plugin creates or reuses one normal Zotero note tagged `vocab-builder`.

- This note is the main vocabulary notebook for the plugin.
- New words, translations, context, and source links are all written into this note.
- Because it is a normal Zotero note, you can search it, edit it manually, sync it with Zotero, and export it.
- After you locate and select this note in Zotero, its content can be viewed from the note/details pane on the right side.

You can find the note in either of these ways:

1. Use the plugin entry that opens the vocabulary note directly.
2. Search for the tag `vocab-builder` in Zotero and open the tagged note manually.

## Quick Start

1. Open a PDF, EPUB, or note in Zotero.
2. Select an English word.
3. Click the floating “Add to vocabulary” button, or press `Alt+A` (configurable in Settings).
4. The plugin adds the word to the vocabulary note immediately and fills translation data in the background.
5. Open the vocabulary note to review the result.
6. Click a source link in the note to jump back to the original place in the reader.

## Installation

1. Build or download `vocabulary-builder.xpi`.
2. In Zotero, open `Tools -> Plugins`.
3. Click the gear button and choose `Install Add-on From File...`.
4. Select `vocabulary-builder.xpi`.
5. Restart Zotero if prompted.

The packaged add-on generated by this repository is usually located at:

`./.scaffold/build/vocabulary-builder.xpi`

## Translation And Settings

Open `Edit -> Settings -> Vocabulary Builder` to configure the plugin.

- Shortcut: record any key combination for quick-add (e.g. `Ctrl+Shift+A`), or reset to `Alt+A`.
- Translation provider: built-in Youdao, Free Dictionary, or a custom JSON API.
- Translation cache path: local cache file for offline lookups (defaults to `plugins/vocab-builder/translation-cache.json` in the Zotero profile directory).
- Batch add: paste multiple words (one per line) and add them at once.
- UI language: Chinese or English.
- Export format and scope.
- Feedback email and donation information.
