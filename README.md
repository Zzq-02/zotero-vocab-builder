# Zotero 生词笔记

Original project name: `Vocabulary Builder`

Collect unfamiliar English words while reading in Zotero, and store them in a dedicated vocabulary note with translation, phonetics, context, and source links.

## Features

### Adding words

- **Keyboard shortcut**: select a word and press `Alt+A` (configurable in Settings).
- **Selection bubble**: when you select a word with the mouse (drag or double-click), a small "＋ Add" bubble appears next to the cursor — on the left/right following your drag direction, or above/below for double-clicks. It can be disabled in Settings.
- **Quick add**: type a word in the Settings pane and add it directly.
- **Batch add**: paste multiple words (one per line, or comma/semicolon separated) in the Settings pane.

### Translation

- Built-in **Youdao** (Chinese translation) and **Free Dictionary** (English definitions), or a **custom JSON API** (URL, headers, and field paths — including an optional example-sentence path).
- **Translation cache** (offline dictionary): results are cached locally so previously looked-up words show their meanings even offline. Cache can be toggled and its file path customized.
- Offline words are kept as pending and retried automatically when back online; failed words are retried up to 3 times.

### Vocabulary note

- One normal Zotero note tagged `vocab-builder` is the vocabulary notebook — searchable, editable and syncable like any note.
- Each entry shows the word with **phonetic transcription** right next to it, plus translation, definition, part of speech, and an **example sentence** from the translation API when available.
- A **source link (↗)** per word jumps back to the exact position in the PDF where the word was selected; the find-highlight color after jumping is configurable.

### Export

- Export as **CSV, TSV, JSON, Anki, Quizlet, or Mochi**, for all words or only completed ones.

### Interface

- Chinese / English UI toggle.
- Feedback email and donation info in the Settings pane.

## Installation

1. Build or download `vocabulary-builder.xpi`.
2. In Zotero, open `Tools -> Plugins`.
3. Click the gear button and choose `Install Add-on From File...`.
4. Select `vocabulary-builder.xpi`.
5. Restart Zotero if prompted.

The packaged add-on generated by this repository is usually located at:

`./.scaffold/build/vocabulary-builder.xpi`

## Settings

Open `Edit -> Settings -> Vocabulary Builder`:

- **Shortcuts**: record a custom quick-add key combination, toggle the selection bubble.
- **Vocabulary**: open the note, quick add, batch add.
- **Translation API**: provider and custom API configuration.
- **Translation cache**: enable/disable and choose the cache file path.
- **Highlight**: color of the jump-back find highlight.
- **Export**: format and scope.
- **About / Donate**: language toggle, feedback, donation.
