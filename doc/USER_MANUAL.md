# Zotero 生词笔记 使用手册

## 1. 插件用途

Zotero 生词笔记（原 `Vocabulary Builder`）用于在 Zotero 阅读文献时快速收集英语生词。你在阅读器里选中单词后，插件会把它写入一条专属的 Zotero 生词笔记，并自动补全翻译、英文释义、词性、音标和例句，方便后续复习、搜索、编辑和导出。

## 2. 生词保存在哪里

插件不会把生词藏在单独的数据库里，而是会创建或复用一条普通的 Zotero 笔记，并给它打上 `vocab-builder` 标签。

- 这条笔记就是插件的生词本。
- 新增的单词、翻译、例句和来源链接都会写进这条笔记。
- 因为它是普通 Zotero 笔记，所以可以被 Zotero 正常搜索、同步、手动编辑和导出。

查看这条笔记有两种常用方式：

1. 通过插件提供的"打开生词表 / Open Vocabulary"入口直接打开。
2. 在 Zotero 里搜索标签 `vocab-builder`，找到这条生词笔记。

## 3. 如何添加生词

### 方式一：快捷键（默认 Alt+A）

1. 在阅读器中选中一个英文单词。
2. 按 `Alt+A`（可在设置中自定义）。
3. 添加成功后右下角出现提示，翻译等内容在后台继续补全。

### 方式二：选中气泡按钮

1. 用鼠标选中单词——**拖动选择**或**双击选词**均可。
2. 气泡会出现在鼠标附近：
   - 拖动选择：气泡在鼠标右侧（从左往右选）或左侧（从右往左选），垂直与鼠标同高；上方空间不足时显示在鼠标下方。
   - 双击选词：气泡水平居中于鼠标，显示在鼠标上方（空间不足时在下方）。
3. 点击气泡即可添加。

如果不想使用气泡，可以在设置中关闭"选中单词时显示气泡按钮"。

### 方式三：手动/批量添加

在设置页的"生词"区域：

- 单行输入框输入单词，点"+ 添加"。
- 批量输入框粘贴多个单词（每行一个，或逗号/分号分隔），点"批量添加"。

## 4. 自定义快捷键

进入 `编辑 -> 设置 -> Vocabulary Builder`，在"快捷键"区域：

- 点击输入框后直接按下新的组合键即可录制，例如 `Ctrl+Shift+A`。
- 也支持手动输入，例如 `ctrl+shift+a`。
- 按 `Esc` 取消录制。
- 点击"重置为 Alt+A"恢复默认。

注意：为避免干扰正常打字，快捷键必须包含 `Ctrl`、`Alt` 或 `Meta` 中的至少一个修饰键。

## 5. 添加后会发生什么

新增生词后，词条会包含：

- 单词本身，以及紧跟在单词旁的**音标**（如 `omega /ˈoʊməɡə/`）
- **翻译**（有道返回中文翻译）
- **英文释义**、**词性**
- **例句**：使用翻译 API 提供的例句（免费词典自带例句；自定义 API 可配置例句路径；有道一般没有），没有则不显示语境
- **来源链接 ↗**：点击可跳回 PDF 中当初选中的位置

## 6. 如何从生词笔记跳回原文

在生词笔记中点击词条的来源链接（↗）：

1. Zotero 会重新打开对应的 PDF。
2. 阅读器回到当初选中的位置（自带定位动画）。
3. 如果该词没有精确位置（如老数据），插件会用查找方式在 PDF 中高亮这个单词。

跳转高亮的颜色可在设置 → "高亮"中自定义，留空使用 Zotero 默认色。

## 7. 自动翻译、翻译缓存与离线重试

- 联网时，插件会在添加生词后自动翻译。
- 翻译结果写入本地**翻译缓存**（离线词库）：之后再遇到同一个单词（包括离线时）直接使用缓存，不再请求网络。
- 离线且缓存未命中时，生词先保存为"待处理"，联网后自动重试；单个词最多重试 3 次。
- 设置 → "翻译缓存"可：启用/禁用缓存、自定义缓存文件路径（绝对路径或文件名，留空用默认位置 `<Zotero 配置目录>/plugins/vocab-builder/translation-cache.json`）。
- 缓存文件是普通 JSON，可备份、迁移或删除（删除后仅离线词库失效，不影响生词笔记）。

## 8. 翻译 API 设置

设置 → "翻译 API"：

- **有道 / Youdao**（内置）：适合中英翻译。
- **免费词典 / Free Dictionary**（内置）：适合英文释义、词性和音标，自带例句。
- **自定义 JSON API**：接入自己的词典、代理服务或大模型接口，支持：
  - 占位符：`{word}`（URL 编码）、`{wordRaw}`（原始单词）
  - 字段路径：翻译、释义、词性、音标、**例句**（可选，如 `data.example`；留空则不显示语境）

## 9. 导出生词

设置 → "导出"：选择格式和范围。

- 格式：CSV、TSV、JSON、Anki、Quizlet、Mochi
- 范围：全部生词，或仅已完成翻译的生词

需要长期备份时推荐定期导出 JSON。

## 10. 界面与反馈

- 设置页右上角可切换**中文 / English**。
- 设置页底部有反馈邮箱和赞赏信息。

## 11. 常见问题

### 添加后没有立即翻译

可能是网络不可用、翻译源请求失败或自定义 API 配置不完整。生词不会丢失，会保留为待处理并在联网后重试；查过的词会直接使用翻译缓存。

### 设置页按钮没有反应

完全退出 Zotero 后重新打开；仍异常则重新安装最新的 `vocabulary-builder.xpi`。

### 生词数量不对

点击设置页中的"从生词笔记导入"，插件会重新扫描生词笔记并合并遗漏的单词。

### 快捷键无效

检查设置 → "快捷键"是否被误改（纯字母键不会被保存）；也可点击"重置为 Alt+A"。

### 怎么备份生词

定期导出 JSON（保留全部字段，适合迁移恢复）；翻译缓存文件可一并备份。

### 来源链接点了没反应

确认链接是在 PDF 阅读器中添加的（笔记/网页中添加的词没有来源位置）；检查 Zotero 版本与插件版本是否匹配，必要时重新安装插件。
