# Zotero 生词笔记 使用手册

## 1. 插件用途

Zotero 生词笔记（原 `Vocabulary Builder`）用于在 Zotero 阅读文献时快速收集英语生词。你在阅读器里选中单词后，插件会把它写入一条专属的 Zotero 生词笔记，并尽量自动补全翻译、英文释义、词性和音标，方便后续复习、搜索、编辑和导出。

## 2. 生词保存在哪里

插件不会把生词藏在单独的数据库里，而是会创建或复用一条普通的 Zotero 笔记，并给它打上 `vocab-builder` 标签。

- 这条笔记就是插件的生词本。
- 新增的单词、翻译、完整例句和来源链接都会写进这条笔记。
- 因为它是普通 Zotero 笔记，所以可以被 Zotero 正常搜索、同步、手动编辑和导出。

查看这条笔记有两种常用方式：

1. 通过插件提供的“打开生词表 / Open Vocabulary”入口直接打开。
2. 在 Zotero 里搜索标签 `vocab-builder`，找到这条生词笔记。

找到并选中这条笔记后，你可以直接在 Zotero 右侧的笔记/详情栏中查看内容，也可以双击笔记进入完整编辑界面。

## 3. 如何添加生词

### 方式一：选中单词后点击气泡按钮（推荐）

1. 在 Zotero 阅读器中打开 PDF、EPUB 或笔记。
2. 用鼠标选中一个英文单词（也可以按 Shift + 方向键选中）。
3. 选区上方会出现绿色的“＋ 加入生词表”气泡按钮，点击即可添加。

### 方式二：使用快捷键

1. 选中一个英文单词。
2. 按默认快捷键 `Alt+A`（可在设置中自定义）。
3. 右下角出现添加成功提示后，生词会立刻写入生词笔记。
4. 翻译、释义、词性和音标会在后台继续补全。

如果插件判断该词已经存在，会提示“重复 / Duplicate”，不会重复写入。

## 4. 自定义快捷键

进入 `编辑 -> 设置 -> Vocabulary Builder`，在“快捷键”区域：

- 点击输入框后直接按下新的组合键即可录制，例如 `Ctrl+Shift+A`。
- 也支持手动输入，例如 `ctrl+shift+a`。
- 按 `Esc` 取消录制。
- 点击“重置为 Alt+A”恢复默认。

注意：为避免干扰正常打字，快捷键必须包含 `Ctrl`、`Alt` 或 `Meta` 中的至少一个修饰键。

## 5. 批量添加

在设置页的“生词”区域有一个批量输入框：

1. 粘贴多个单词，每行一个（也支持用逗号、分号分隔）。
2. 点击“批量添加”。
3. 完成后会提示本次新增和跳过的数量（重复或无效的单词会被跳过）。

适合从论文词汇表、考试词库一次性建立生词本。

## 6. 添加后会发生什么

新增生词后，插件会尽量保留以下信息：

- 单词本身
- 选取单词所在的完整原文例句（自动摘录）
- 来源超链接
- PDF 中的原始选取位置
- 翻译、英文释义、词性、音标

这意味着你后续不仅能看到词义，还能从生词笔记跳回当时阅读的位置。

## 7. 音标显示

生词笔记中的每个词条都会在单词旁边直接显示音标（例如 `omega /ˈoʊməɡə/`），无需任何操作即可查看。

音标由翻译源自动补全（有道/免费词典/自定义 API 的 phonetics 字段）；如果翻译源没有返回音标，则该词条不显示音标，不影响其他字段。

## 8. 如何从生词笔记跳回原文

如果这个词是在 PDF 阅读器里添加的，插件会保存当时选中的精确位置。

在生词笔记中点击该词对应的来源链接后：

1. Zotero 会重新打开对应的 PDF。
2. 阅读器会回到当时选中的位置。
3. Zotero 会显示一个短暂的定位提示，帮助你看见原始位置。

插件不会为了这个跳转额外给原文留下永久高亮，因此不会改乱你原本的标注颜色。

## 9. 自动翻译、翻译缓存与离线重试

- 联网时，插件会在添加生词后自动尝试翻译。
- 翻译成功后，结果会写入本地翻译缓存（离线词库）。
- 之后再遇到同一个单词（包括离线时），会直接使用缓存结果，不再请求网络。
- 离线且缓存未命中时，插件会先把单词保存为待处理状态。
- 重新联网后，插件会自动重试待处理或失败的生词。
- 如果某个词多次翻译失败，仍会保留在生词笔记中，避免丢词。

### 自定义缓存路径

在设置页的“翻译缓存”区域可以配置缓存文件位置：

- 留空：使用默认位置 `<Zotero 配置目录>/plugins/vocab-builder/translation-cache.json`。
- 填写绝对路径：使用该文件作为缓存（例如 `D:\VocabCache\cache.json`）。
- 仅填写文件名：放在默认目录下（例如 `my-cache.json`）。

缓存文件是普通 JSON，可以自由备份、迁移或删除（删除后只是离线词库失效，不影响生词笔记）。

## 10. 翻译 API 设置

进入 `编辑 -> 设置 -> Vocabulary Builder`，可配置翻译源和界面语言。

支持的翻译方式包括：

- 有道 / Youdao：适合中英翻译。
- 免费词典 / Free Dictionary：适合英文释义、词性和音标。
- 自定义 JSON API：适合接入自己的词典、代理服务或大模型接口。

自定义 JSON API 支持以下占位符：

- `{word}`：URL 编码后的单词。
- `{wordRaw}`：原始单词。

字段路径示例：

- `data.translation`
- `result.definitions.0.text`
- `items[0].phonetic`

## 11. 导出生词

在设置页的“导出”区域可以选择格式和范围。

支持的格式包括：

- CSV
- TSV
- JSON
- Anki
- Quizlet
- Mochi

范围可选择全部生词或仅导出已完成翻译的生词。

如果你需要长期备份，推荐定期导出 JSON。

## 12. 常见操作建议

- 想快速查看全部生词：直接打开生词笔记。
- 想在右侧笔记栏查看：先找到并选中那条带 `vocab-builder` 标签的生词笔记。
- 想手动修正某个词：直接编辑那条 Zotero 笔记即可。
- 想确认是否漏词：使用“从生词笔记导入”重新扫描。
- 想查看音标：每个词条都在单词旁直接显示音标。

## 13. 常见问题

### 添加后没有立即翻译

可能是网络暂时不可用、翻译源请求失败，或自定义 API 配置不完整。生词不会丢失，插件会保留待处理状态并在联网后重试；如果之前查过这个词，会直接使用翻译缓存。

### 设置页按钮没有反应

请先完全退出 Zotero，再重新打开。如果仍然异常，重新安装最新的 `vocabulary-builder.xpi`。

### 生词数量不对

点击设置页中的“从生词笔记导入”，插件会重新扫描已有生词笔记并合并遗漏的单词。

### 如何备份生词

推荐定期导出 JSON。JSON 会保留插件内部保存的完整字段，适合迁移或恢复。翻译缓存文件也可以一并备份。

### 快捷键无效

检查设置页中“快捷键”一栏是否被误改（例如改成了不带修饰键的纯字母键，插件会拒绝保存）。也可以点击“重置为 Alt+A”恢复默认。

### 音标没有显示

翻译源没有返回音标（phonetics）字段时，词条不显示音标。可以尝试切换翻译源（如有道/免费词典），或使用返回 phonetics 字段的自定义 API。
