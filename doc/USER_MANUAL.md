# Vocabulary Builder 使用手册

## 1. 插件用途

Vocabulary Builder 用于在 Zotero 阅读文献时快速收集英语生词。插件会将生词保存到一个专属 Zotero 笔记中，并尽量自动补全翻译、英文释义、词性和音标，方便后续复习和导出。

## 2. 添加生词

1. 在 Zotero 阅读器中打开 PDF、EPUB 或笔记。
2. 选中一个英文单词。
3. 按 `Alt+A`。
4. 右下角出现添加成功提示后，生词会进入生词表。

如果插件判断该词已经存在，会提示“重复 / Duplicate”，不会重复写入。

## 3. 查看生词表

可以通过以下任一方式打开生词表：

- 在 Zotero 菜单中选择插件的生词表入口。
- 在插件设置页点击“打开生词表”。

生词表是 Zotero 普通笔记，可以搜索、复制，也可以手动补充内容。插件会优先识别带有内部标记和标签的生词笔记，避免每次重启后重新创建。

## 4. 离线与自动翻译

- 联网时，插件会在添加生词后自动尝试翻译。
- 离线时，插件会先把单词保存为待处理状态。
- 重新联网后，插件会自动重试待处理或失败的生词。
- 如果某个词多次翻译失败，仍会保留在生词表中，避免丢词。

## 5. 翻译 API 设置

进入 `编辑 -> 设置 -> Vocabulary Builder`，先可用顶部 `中文 / English` 按钮切换界面语言，再在“翻译 API”区域选择服务：

- 有道 / YouDao：内置默认源，适合中英翻译。
- 免费词典 / Free Dictionary：使用英文释义、词性和音标。
- 自定义 JSON API：适合接入自己的词典、代理服务或大模型服务。

自定义 JSON API 支持以下占位符：

- `{word}`：URL 编码后的单词。
- `{wordRaw}`：原始单词。

字段路径示例：

- `data.translation`
- `result.definitions.0.text`
- `items[0].phonetic`

## 6. 导出生词

在设置页的“导出”区域选择格式和范围：

- CSV：通用表格格式。
- TSV：适合复制到表格或部分背词工具。
- JSON：完整备份所有字段。
- Anki：导出为 Anki 可导入的制表符文本。
- Quizlet：导出词条和释义两列。
- Mochi：导出 Mochi 支持的 CSV。

范围可选择全部生词或仅导出已完成翻译的生词。

## 9. 常见问题

### 添加后生词没有立即翻译

可能是网络暂时不可用、翻译源请求失败，或自定义 API 配置不完整。生词不会丢失，插件会保留待处理状态并在联网后重试。

### 设置页按钮没有反应

请先完全退出 Zotero，再重新打开。如果仍然异常，重新安装最新的 `vocabulary-builder.xpi`。

### 生词数量不对

点击设置页中的“从生词笔记导入”，插件会重新扫描已有生词笔记并合并遗漏的单词。

### 如何备份生词

推荐定期导出 JSON 备份。JSON 会保留插件内部保存的完整字段，适合迁移或恢复。
