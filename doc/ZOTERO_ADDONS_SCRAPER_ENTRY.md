# zotero-addons-scraper 提交条目

如果插件公开发布在 GitHub 仓库 `Zzq-02/zotero-vocab-builder`，提交到 `syt2/zotero-addons-scraper` 的条目应为：

文件名：

```text
Zzq-02@zotero-vocab-builder
```

文件内容：

```json
{"tags": ["reader", "notes"]}
```

标签说明：

- `reader`：插件围绕 Zotero 阅读器中的选词、定位和返回原文工作。
- `notes`：插件把生词保存到 Zotero 笔记中，并以笔记作为主要查看入口。

正常发新版时不需要重新提交这个条目。只有在仓库地址、标签或收录信息发生变化时，才需要更新。
